# murfalo.com

![CI](https://github.com/murfalo/murfalo.github.io/actions/workflows/ci.yaml/badge.svg)

Personal landing page with an interactive WebGL lava lamp background. Built with SvelteKit, Vite+ and pnpm. Prerendered to static HTML and deployed to GitHub Pages on push to `main`.

```sh
pnpm install
pnpm dev
```
